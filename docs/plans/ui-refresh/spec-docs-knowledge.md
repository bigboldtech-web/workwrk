A template has no Share at all: access §3.3 already says "creator FULL; Admin FULL; every Member VIEW", so there is nothing to grant. - Access: who can reach each route (org role, object role, manager chain), what a read-only viewer sees, the denial behaviour (one convention)

  - `/docs/[id]`: `BackButton{fallbackHref}` in the title row; fallback = `/docs/[parentId]` for a sub-doc, else the anchor page for an anchored doc (`/spaces/[slug]`, `/folders/[id]`, `/boards/[slug]`, `/item/[id]`), else `/docs`. - Dates, times and numbers (one helper, critic #13): no route in this unit formats a date itself. Every "smart date", "Uploaded", "Edited", "When", "Date viewed" and tooltip goes through the one `formatDate(value, prefs)` helper in `src/lib/format/date.ts`, which reads `home.locale.dateFormat` (`DMY` / `MDY` / `YMD`), `home.locale.timeFormat` (`12h` / `24h`) and `home.locale.timezone` from `getEffectivePreferences` (settings §4.2). **Smart date is defined once**: today renders as the time, the last seven days as the weekday, the current year as day and month, anything older as day, month and year; the exact date and time in the viewer's zone is the `title` tooltip on every one of them. A viewer with no saved preference falls through to the org values, which is what `getEffectivePreferences` already does for theme.
- List sizes and refresh (critic #12): every list page in this unit is server-paginated with a cursor and a real total (40 rows by default, 100 on request); the 200-row doc cap, the 200-row canvas cap, the 500-row file cap and the client-side filtering behind them are deleted with the pages that had them.
